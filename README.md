# FN-Yorum-Analiz-Raporu — Çalıştırma Talimatları (Öneri)\n\nBu repo bir statik frontend (index.html + main.js) içeriyor. Gerçek zamanlı yorum çekme ve analiz için basit bir backend ekledim (server.js). Aşağıdaki adımlarla yerelde çalıştırabilirsin.\n\nÖnkoşullar:\n- Node.js (14+ veya 16+ önerilir)\n- İnternet erişimi (hedef sitelere istek için)\n\nKurulum ve çalıştırma:\n1. Repo'yu klonla / projeyi al: \n   git clone https://github.com/faruk066/FN-Yorum-Analiz-Raporu.git\n   cd FN-Yorum-Analiz-Raporu\n\n2. Dosyaları ekle/üzerine yaz (server.js, package.json ve main.js) — bunlar önerilen değişikliklerdir.\n\n3. Bağımlılıkları yükle:\n   npm install\n\n4. Sunucuyu başlat:\n   npm start\n   - Sunucu http://localhost:3000 adresinde çalışacaktır.\n   - Tarayıcıda http://localhost:3000/index.html adresini aç.\n\nKullanım notları ve sınırlamalar:\n- Bu backend demo amaçlıdır. Birçok e-ticaret sitesi veya yorum platformu botları, basit axios taleplerini engelleyebilir (Cloudflare, bot korumaları vb.). Bu durumda daha gelişmiş scraping / proxy çözümleri gerekir.\n- Yorum çekme için kullanılan selector'lar genel ve basittir; her site farklı DOM yapısına sahip olduğu için sonuç değişir.\n- Prod ortamı için HTTPS, rate-limiting, istek sırası yönetimi, kullanıcı kimlik doğrulama, gizlilik politikaları ve yasal izinlere dikkat etmelisin.\n- Büyük ölçekli analiz için server tarafında paralel işleme, job queue ve daha iyi NLP modelleri (ör. Transformer tabanlı) düşünmelisin.\n\nİstersen:\n- Benim sunduğum backend'i kurmana yardımcı olabilirim,\n- Veya mevcut index.html / mevcut main.js üzerinde doğrudan küçük düzeltmeler gösterip, adım adım deploy talimatı verebilirim.
